edge-reference-check

Check what an edge Linux system reports about itself against a profile. Everything below runs in this tab and is gone when you close it. Nothing is uploaded.

1. Bundle

On the device, run collect.sh as root. Paste the file it wrote, or load it.

no file loaded

2. Profile

A profile is a list of checks. The built-in one is this project's editorial baseline. A publisher's or your own profile can be loaded from a JSON file.

no file loaded

3. Result

StatusCheckObservedExpected

This is level 1: configuration as the system reported it. The bundle is not signed, so a system that has been tampered with can report anything. UNAVAILABLE means the device did not expose that fact and the check could not run. NOT APPLICABLE means the profile expects that interface to be closed on this kind of system, which is a hardening decision rather than a gap. Neither is a failure.

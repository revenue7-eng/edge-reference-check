This is level 1: configuration as the system reported it. The bundle is not signed, so a system that has been tampered with can report anything. UNAVAILABLE means the device did not expose that fact and the check could not run. NOT APPLICABLE means the profile expects that interface to be closed on this kind of system, which is a hardening decision rather than a gap. Neither is a failure.

Level 3: a signed envelope against a signed reference set

Level 3 needs two things from two different parties. From the publisher: a reference set and its signature. From the device: an attestation envelope, its signature, and the device's public key. The page checks the reference set's signature against a root certificate you have pinned yourself, then checks the envelope's signature with the device key, then whether the attested state is one the reference set recognises.

Formats this page reads: reference sets in tactiq-rim/1 with a detached CMS signature; envelopes in the 93-byte attest-envelope layout signed with ECDSA P-256. The envelope check is the publisher's open crate attest-appraise, compiled to WebAssembly from a pinned commit; the build is reproducible, see wasm/build.sh in this repository. A system that publishes another format is recorded in the catalog as such; this page does not read it yet.

The root is yours to choose and pin. The page shows the SHA-256 of its public key after the check; compare it with the value the publisher states through a channel you trust. A reference set carries its own idea of its root, and that is exactly the value a forger would also write, so the page does not use it.

    OK here means: the reference set was signed under the root you pinned, the envelope was signed by the key you supplied, the evidence bundle is the one that was signed over, and the attested state is one the reference set recognises. It does not mean the envelope is the device's latest: that needs a record of the previous check, and this page keeps nothing. The counter is shown so that you can compare it yourself. Whether the key you supplied belongs to the device you think it does is outside the envelope and outside this page.
